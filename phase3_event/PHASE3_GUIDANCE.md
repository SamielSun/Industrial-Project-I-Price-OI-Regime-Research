# PHASE 3 要做的实验

下面 17 个实验：第 1–9 个用来判定，第 10–16 个只报数，第 17 个是唯一的稳健性。

---

## 先说共同的设定（跑之前定死，不许改）

| 项 | 值 |
|---|---|
| 主样本 | headline：当月流动性前 50 的名单内，**256,079 个事件** |
| 次要样本 | full：全部 285 个合约，**923,235 个事件**（只作稳健性） |
| 事件定义 | 某一小时里，价格和 OI **都**超过该合约自己过去 90 天的第 70 分位 |
| 前向期 | **四个等权**：1 / 4 / 8 / 24 小时，同一结构全部做 |
| 收益的处理 | **市场中性**（每小时减全市场 701 万行的等权均值）+ **全池 1%/99% 截尾** |
| 波动的处理 | 取对数；**不中性化、不截尾** |
| 方向 | `sign(price_change)`：+1 涨、−1 跌 |
| 幅度 | `abs(price_change) / price_thr`，事件里 ≥ 1，中位数 1.79 |
| 推断（实验 1–4）| **合约固定效应 + 按合约聚类**（249 个簇）。只比同一个合约内部的差异，币与币之间的水平差全部消掉 |
| 推断（实验 5–9）| **不加固定效应**，只按合约聚类。基线问的是策略层面"这个信号单独能不能用"，不是"同一个币内有没有差异" |
| 单位 | 内部一律小数；表格输出转百分数 |
| 判定 | 看 t 和 p，绝对值超过 1.96 即显著；**不做联合检验、不做等价性检验** |

三条为什么必须这么定：

- 不减市场因子，R4 的 +0.298% 里只有 +0.022% 是它自己的（共同因子占 35% 方差）
- 不截尾，峰度是 **162**（截尾后 6.1），少数极端值会主导均值
- 不按合约聚类，t 会虚高（DiD 的 SE 从 4.66bp 缩到 3.44bp）

# 一、判定的 9 个实验

> **原假设（note 原文）**
>
> *"Price/OI regimes do not improve prediction of future returns, volatility, or reversal behavior compared with simple price momentum alone."*
>
> **拆成三条，由实验 1–4 回答：**
>
> | 条款 | 谁回答 |
> |---|---|
> | future returns | 实验 1（均值）+ 实验 2（中位数）|
> | volatility | 实验 3 |
> | reversal behavior | 实验 4 |
>
> 四个实验**共用同一个结构**：每个状态 vs **同向价格超阈、剔除自己**的行——
> 那批行就是"simple price momentum alone"。四个实验只换统计量。

## 1. 收益 · 均值

- **问什么**：note §2 —— 价格移动**伴随** OI 变化，比"只有价格移动"多给多少
- **样本**：headline、`excl_reason == ok`、四个前向期等权、`ok_{h}h`；**全部价格超阈的行**
  （h=24 时：事件 255,807 + OI 安静 298,682 = 554,489）
- **怎么比**：每个状态单独比，基准是"**同样价格超阈、但不是这个状态**"的行（基准剔除自己）

| 状态 | 它的基准 |
|---|---|
| R1 | 价格超阈上涨、但不是 R1 的行（R2 + OI 安静）|
| R2 | 价格超阈上涨、但不是 R2 的行（R1 + OI 安静）|
| R3 | 价格超阈下跌、但不是 R3 的行（R4 + OI 安静）|
| R4 | 价格超阈下跌、但不是 R4 的行（R3 + OI 安静）|

- **方法**：**合约内比较**（合约固定效应）——每个合约各算各的差，再汇总
- **统计量**：差 = 该状态均值 − 基准均值，在合约内计算；标准误按合约聚类（249 个簇）
- **判定**：四个差各自 |t| > 1.96 即显著；另报四个差的平均
- 四个前向期等权，同一结构全部做

## 2. 收益 · 中位数

- **问什么**：同实验 1 的四个对比，但看**典型事件**（中位数）而不是平均值
- **样本**：同实验 1（headline、`ok`、四个前向期等权）
- **怎么比**：同实验 1 的四组对比，基准同样是"**同方向、剔除自己**"

| 状态 | 它的基准 |
|---|---|
| R1 | 涨、但不是 R1 的行 |
| R2 | 涨、但不是 R2 的行 |
| R3 | 跌、但不是 R3 的行 |
| R4 | 跌、但不是 R4 的行 |

- **方法**：**合约内做差，再汇总**——每个合约算一个中位数差

```
Δ_s = median(该状态的行) − median(基准的行)      s = 1 … 249
```

- **统计量**：差 = 这 **249 个数**的平均
- **推断**：在 249 个数上做**单样本 t 检验**

```
t = mean(Δ) / ( sd(Δ) / √249 )        df = 248
```

  分母估的是"真实效应方差 + 估计误差方差"，**只会偏大不会偏小**——所以这个 t 检验偏保守，不会假阳性
- **判定**：|t| > 1.96
- **附带**：报 249 个差里为正 / 为负的**比例**。方向一致的比例高，"不是几个大币的故事"就有了直接证据
- **和实验 1 的关系**：同一个结构（合约内做差 → 汇总），只差两件事——
  统计量是**中位数**而不是均值；汇总是**合约等权**（一人一票）而不是加权。
  等权是中位数本身的性质决定的（没有对应的最小二乘版本），不是妥协

## 3. 波动

- **问什么**：给定价格超阈，OI 状态能不能预测事后的已实现波动（note 的 volatility 条款）
- **样本**：headline、`excl_reason == ok`、四个前向期等权、`ok_{h}h`
  - **必须含 OI 安静行**，否则没有"只看价格"的基准
- **怎么比**：同实验 1 的四个对比，因变量换成 `log(rv_h)`

| 状态 | 它的基准 |
|---|---|
| R1 | 涨、但不是 R1 的行（R2 + OI 安静）|
| R2 | 涨、但不是 R2 的行（R1 + OI 安静）|
| R3 | 跌、但不是 R3 的行（R4 + OI 安静）|
| R4 | 跌、但不是 R4 的行（R3 + OI 安静）|

- **方法**：合约内比较（合约固定效应），同实验 1
- **统计量**：差 = 该状态的 `log(rv_h)` 均值 − 基准的，在合约内计算；按合约聚类；报 `exp(差) − 1` 转成百分比
- **判定**：四个差各自 |t| > 1.96
- **1 小时那一列要单独解读**：`rv_1h ≡ |log(1 + fwd_1h)|`（实测最大差 1.4e-07），
  只用了**一根 bar**，它不是波动率，是"这一小时涨跌的幅度"。所以 1h 测的是
  "状态能不能预测下一步的移动幅度"，与收益高度机械相关——**读数时不要和 4/8/24 小时混在一起看**


## 4. 反转程度

- **问什么**：note 的第三条——相比**只看价格**，四个状态能不能改进"冲击幅度 → 之后收益"这个关系的预测
- **样本**：同实验 1（headline、`ok`、四个前向期等权、`ok_{h}h`）
- **怎么比**：每个状态单独跑一个回归，样本是**该方向的全部行**（该状态 + 同向补集）

```
y = a + b·1[该状态] + c·log(shock) + d·1[该状态]·log(shock)
```

| 系数 | 是什么 |
|---|---|
| `c` | **只看价格**的斜率（同向补集）|
| `c + d` | 该状态的斜率 |
| **`d`** | **两者之差** ← 要检验的就是这个 |

- **四个回归**：R1、R2 在"全部价格超阈上涨"的行上跑；R3、R4 在"全部价格超阈下跌"的行上跑；
  每个回归都带**合约固定效应**
- **推断**：按合约聚类
- **判定**：四个 `d` 各自 |t| > 1.96

- **为什么不用"续势/反转比例"**：它和命中率是恒等式（32 格完全相等），不能当检验

## 5. 纯价格基线

- **问什么**：note §9 第 1 条——价格方向**单独**能不能预测收益
- **样本**：headline、`excl_reason == ok`、四个前向期等权；只要求价格超阈，**不管 OI**
  - 上涨组：价格 > +门槛
  - 下跌组：价格 < −门槛
- **方法**：多空价差 = 上涨组均值 − 下跌组均值；按合约聚类
- **判定**：价差的 |t| > 1.96

## 6. 纯 OI 基线

- **问什么**：note §9 第 2 条——OI 增加或减少**单独**能不能预测收益
- **样本**：headline、`excl_reason == ok`、四个前向期等权；只要求 OI 超阈，**不管价格**
  - 增加组：OI 变化 > +门槛
  - 减少组：OI 变化 < −门槛
- **方法**：多空价差 = 增加组均值 − 减少组均值；按合约聚类
- **判定**：价差的 |t| > 1.96

## 7. 纯 funding 基线

- **问什么**：note §9 第 3 条——资金费率状态**单独**能不能预测收益
- **样本**：headline、`excl_reason == ok`、四个前向期等权；按 funding 四档分
  - 低于 p25 / 中间 / 高于 p75 / 高于 p90
- **方法**：多空价差 = 高于 p75 组均值 − 低于 p25 组均值；按合约聚类
  - ⚠️ **extreme（> p90）是 high（> p75）的子集**，两者重叠，不是分区
- **判定**：价差的 |t| > 1.96

## 8. 随机时点基线

- **问什么**：note §9 第 4 条——随机选的时间点会不会给出类似的结果
- **样本**：headline 事件
- **方法**：每个事件**合约不变、时刻换掉**——从该合约**在 headline 名单内的全部小时**里随机抽一个
  （抽出来的时刻不要求价格超阈，这正是 placebo 的意义）。抽 1000 轮，每轮重算一次；
  报随机分布的中位数与 [p5, p95]
- **判定**：事件原值落在随机分布的 [p5, p95] 之外 → 事件时刻是特殊的

## 9. 五个价差并排

- **问什么**：note §9 最后一句——四状态是不是比这些简单基线**更好**
- **样本**：每组用各自的样本（实验 5–8），四状态用 R1 / R4；headline、四个前向期等权
- **方法**：五个多空价差放同一张表，**再加"四状态 − 该基线"的差值**

| 组 | 多头 | 空头 |
|---|---|---|
| 纯价格 | 价格极端上涨 | 价格极端下跌 |
| 纯 OI | OI 极端增加 | OI 极端减少 |
| 纯 funding | 高于 p75 | 低于 p25 |
| 四状态 | R1 | R4 |
| 随机 | R1 事件，合约不变、时刻随机 | R4 事件，合约不变、时刻随机 |

  - 四条基线与四状态的行**互相重叠**（R1 就在"价格上涨"里），差值必须从**联合协方差**取，
    **不能拿两组各自的 SE 开根号相减**
- **判定**：五个价差各自的 |t|；四个差值各自的 |t|（|t| > 1.96 即"四状态显著优于该基线"）

> **两个边界**
>
> 1. "四状态 − funding" 的差值只说明两个价差差多少，**不等于**"四状态在 funding 之外还有信息"。
>    后者是 Phase 4 的 4×4 网格。
> 2. 价差全都是负的（截尾不对称把水平压到约 −8.4bp），所以差值为**正**才是四状态更好（少亏）。

# 二、只报数、不做判定的 7 张表

这些是 note 原文要求交付的，报数即可，**表里不放 p 值**。

## 10. 每格的基本面

每个状态、每个前向期（1/4/8/24）：n、平均收益、中位收益、**命中率（原始口径：押对方向的比例）**、
事后波动、被截尾比例。

## 11. 续势 / 反转 / 无效应比例

三个比例相加为 1。**表注必须写明：它和命中率互为恒等式，不是独立证据。**

## 12. 路径风险

最大有利偏移、最大不利偏移、最大回撤，各给均值和 10/50/90 分位。
**这三列不截尾**，均值会被极少数极端路径主导（最差的一条回撤 −382%），只看分位数。

## 13. 事件研究图

事件前后各 24 小时的平均与中位累计收益，带 95% 区间。**每个 k 上的样本量恒定**（不随 k 漂移）。
**左边大是因为事件就是被大移动选出来的；右边纵轴只有 1 个百分点，不要和左边比陡峭程度。**
用中位数讲典型情况，不要用均值。

## 14. 四条基准并排

纯价格、纯 OI、纯 funding（四档）、随机时点，各自的水平（不是价差）放在一张表里。

## 15. 分合约、分市场状态

每个合约、每个波动状态（**只有 low / mid / high**）下的收益和命中率。
`unknown` 已排除——它不是市场状态，是波动率分位没攒够一年时的占位（事件里只落在 2022-03 那个月）。
**不做任何显著性检验。**

## 16. IC 衰减

**纯价格动量的 IC 和四状态分数的 IC 并排**。

- **分数**：四状态 = R1 取 +1、R4 取 −1、其余（R2 / R3 / 非事件）取 0；纯价格 = `sign(price_change)`
- **收益**：原始前向收益（IC 衡量排序能力，不中性化、不截尾）
- **每小时**：算一次横截面 **Spearman**（分数的排名 vs 收益的排名）；横截面少于 20 个合约的小时剔除
- **汇总**：几千个小时的 IC 求平均；时间序列上用 **Newey-West，滞后 = h**
- **判定**：|t| > 1.96

⚠️ 这个比较对四状态**不利**：它的分数是稀疏的（每小时 50 个合约里只有少数是 ±1，其余是 0），
IC 天然被稀释。**两者不能直接比大小**——四状态要赢，得在稀释之后还赢。

# 三、稳健性 1 项
