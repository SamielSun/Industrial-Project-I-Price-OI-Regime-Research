# 审稿意见：对 null 的最小充分检验集

被审的对象：`phase3_event/PHASE3_GUIDANCE.md` 的 13 个实验 + `DECISIONS.md` 的口径。
最高权威：`research_archive/build_scripts/_build/mentor_note_extracted.md`（下称 note）。

## 0. 一句话结论

**现在的设计不能判掉 null，也不能判成立 null**——因为它测的 32 个格均值没有一个是 null 的检验（null 是嵌套模型限制，不是"均值为 0"），而 null 明写的"volatility"这一条从来没有被检验过（随机时点那 4 行的 `mean_rv` 全是 NaN）。
按下面这一组检验重做之后，我预期（依据我下面第 1 节的实测探针）结论会变成：**四状态对收益的"位置"没有可交易的信息，但对"二阶矩"（已实现波动、过度反应幅度）有稳定、可检出的信息；而四格之间的交互（这才是"四状态框架"的全部内容）在三个维度上要么为零、要么小到没有经济含义。** 这与现在口径里"c 和 g 都不显著 → null 成立"是两个不同的结论，必须换。

## 1. 三件会改变设计的事（我实测，先摆在这里）

### 1.1 命中率、续势、反转是同一个数——实验 3 是恒等式，不是检验

用 `outcomes.parquet` 直接验：

| 检查 | 最大偏差 |
|---|---|
| `hit_rate − p_cont` | **0.00e+00**（四个前向期全为 0） |
| `p_cont_minus_rev − (2·hit_rate + p_flat − 1)` | ≤ 9.7e-17 |
| `p_cont + p_rev + p_flat − 1` | ≤ 2.2e-16 |

因为 `cont` 的定义就是"前向收益符号 = 事件方向符号"，而这正是 `hit` 的定义。所以 note §10 要的 "reversal probability / continuation probability" 在这套数据里**是一个数的三种写法**，三列只携带一个自由度。实验 3 整张表对 null 的贡献为零。

推论：**"用哪个统计量"是本设计里最大的一个隐含自由度，比门槛 p70/p80 大得多。必须在跑数之前钉死，否则任何结论都可以被自己的稳健性表推翻。**

### 1.3 IC 的分数里根本不含交互项（代数，不是数据）

现在的打分是 R1=+1、R4=−1、其余 0。令 `S_P = sign(价格变动)`、`S_O = sign(OI变动)`，则在这四格上恒有

```
S = ½ (S_P + S_O)        # R1:½(1+1)=+1  R2:½(1−1)=0  R3:½(−1+1)=0  R4:½(−1−1)=−1
```

也就是说：**这个分数是"价格分数 + OI 分数"的和，完全没有 `S_P·S_O` 那一项**，而 `S_P·S_O` 才是四格对比 (= (R1−R2)−(R3−R4)) 的分数。所以实验 8 的 16 个负 IC 在结构上不可能检验"四状态"这个假设；它只能检验"价格 + OI 可加"，而那正是 null 允许的东西。

实测（我在"价格超门槛"子样本上按小时做 Fama–MacBeth，h=1，19,287 个小时，秩）：

| 分数 | 系数 | t |
|---|---|---|
| `S_P`（价格方向） | −0.0176 | **−19.4** |
| `S_O`（OI 方向） | +0.0006 | +0.56 |
| `S_P·S_O`（交互 = 四状态） | −0.0003 | **−0.29** |

**控制价格方向之后，OI 和交互的横截面预测力精确为零。** 16/16 为负的 IC 是 100% 的价格反转。这一条如果不改，报告会被审稿人一句话打掉："你的 IC 与价格动量共线，不能区分你的假设与零假设。"

## 4. 缺失：补什么（三个识别问题）

### 4.1 "条件在两个极端上"到底毁了什么——以及怎么修

**没毁掉的那部分（先说清楚，免得过度悲观）**：四格是 (价格符号, OI 符号) 的 2×2，四格均值可以**正交**分解成 4 个对比，一个都不缺识别：

| 对比 | 自由度 | 问题 |
|---|---|---|
| 总平均（市场漂移） | 1 | 与 null 无关，是描述量 |
| 价格符号 `P` | 1 | **这就是"价格动量基准"**——null 的比较对象 |
| OI 主效应（可再拆 2 个） | 2 | **"OI 维度有没有用"** |
| `P`×OI 交互 | 2 | **"四格之间有没有差别"** |

所以我建议把 6 格做成一个饱和模型（价格符号 × OI 三态：极端降 / 安静 / 极端升）：

```
y = α + β_P·P + β_q·q + β_q2·q² + β_Pq·P·q + β_Pq2·P·q²  + [价格冲击控制] + FE
      q  = +1 (OI极端升) / 0 (安静) / −1 (OI极端降)
      q² = 1 (OI极端) / 0 (安静)
```

- **"OI 维度有没有用"** = {q, q²} 的 **2 df** 联合检验（q² 是关键：它只问"OI 动不动"，不问方向）
- **"四格之间有没有差别（超出可加性）"** = {P·q, P·q²} 的 **2 df** 联合检验
- **"四状态 vs 只有价格动量"** = 上面四个的 **4 df** 联合检验（= 嵌套模型 M1 对 M6）

三个问题、三个正交的 df 块、一张表一次报完。这就是把它们"分开"的办法。现在的实验 7 做不到，因为它①用的是原始收益（市场漂移压在截距里）、②用 0/1 编码所以报出的 `O` 系数是"价格降时的 OI 效应"而不是 OI 主效应、③只报两个 1 df 的 t，没有联合检验。

**真正毁掉识别的是第二件事——强度混杂。** 给定价格已极端，OI 极端的格子价格冲击明显更大：

| 格 | 中位 \|pc\|/thr | 中位 \|oi\|/thr | 高波动状态占比 |
|---|---|---|---|
| 价升 OI 降 (R2) | 1.719 | 1.717 | 46.2% |
| 价升 OI 安静 | 1.431 | 0.417 | 40.3% |
| 价升 OI 升 (R1) | 1.868 | 2.185 | 38.1% |
| 价降 OI 降 (R4) | 1.810 | 1.948 | 38.7% |
| 价降 OI 安静 | 1.426 | 0.427 | 38.8% |
| 价降 OI 升 (R3) | 1.707 | 1.848 | 43.5% |

R1 的价格冲击比 R2 大 8.7%，比"OI 安静"格大 30%；R2 处在高波动市场的频率比 R1 高 8 个百分点。**所以现在的 R1−R2 同时是"OI 方向"和"涨得更多 + 市场更慌"两件事的混合。** 任何 OI 对比都必须把价格冲击强度放进控制（十分位虚拟变量或连续秩），否则结论无法归因。这一条比"能不能分开 OI 与四格"更致命，而且现在完全没做。

**还有一部分确实无法识别，必须写明**：这套设计只能对"价格与 OI 同时极端"这个子总体下结论。OI 在安静区内部（\|oi\| 在 p70 以下）的变化不可识别；把结论外推到"OI 越极端越好"必须靠连续 OI 分位秩，而且要标明是外推。可以顺手做一次（几乎零成本）：在价格极端样本内，用 OI 分位秩（0–1 连续）替代三态，看斜率与它和 P 的交互——**如果离散版本交互为 0 而连续版本显著，说明错的是 p70 这个切点，不是四状态的想法**。这是唯一能区分"机制错"与"切点错"的一行代码，值得留。

### 4.2 波动从来没被检验过——而它是唯一会被拒的一条

现状：`baselines.parquet` 里 `random_R1..R4` 四行的 `mean_rv` 全部是 **NaN**。指南第 47 行写"波动的结论只能跟第 6 条的随机时点比"，而那个基准不存在。所以 note 明写的 "volatility" 这一条，**至今零检验**。

我按 §4.1 的模型跑了一遍（log rv24，控制价格冲击十分位，symbol 聚类）：

| 规格 | OI 块 χ²(4 df) | OI 主效应(2 df) | 交互(2 df) | q²（OI 极端 vs 安静） |
|---|---|---|---|---|
| 无 FE | 1440 | 786 | 369 | +0.063 (t=20.3) → **+6.5% 波动** |
| + 时点 FE | 609 | 369 | 200 | +0.045 (t=17.7) |
| + 时点 + 合约 FE | 1165 | 598 | 308 | +0.050 (t=24.4) |

对照：同一个模型换成"市场中性、1% winsorized 的 24h 收益"，OI 块 χ² 只有 **20.6**（full）/ **11.4**（headline）。

也就是说：**同一个 4 df 的 OI 块，在波动方程里 χ² 是收益方程的 30–70 倍（视 FE 规格）。** 结论会很干脆：joint price/OI 状态不是方向状态，是**波动状态**。这不是"没找到效应"，这是一个可以被拒的、有经济含义的结论（对应 note §8B），而现在的设计完全看不到它。

设计要点（三点，缺一不可）：
1. **必须控制价格冲击的大小**，否则"事件后波动高"是同义反复（事件本来就是按大波动选出来的）。
2. **必须用 log rv 或用该合约自身的波动水平标准化**，否则测的是"哪些合约天生波动大"，不是状态效应。
3. 基准不是"无条件均值"，而是"同一价格冲击十分位内的均值"（随机时点的全部作用已经被这个条件期望吸收，不必真跑 1000 轮；要跑也可以用 D4 描述表的随机样本作交叉验证，但必须先把 rv 记下来）。

### 4.3 波动之外，"反转"要怎么和 hit rate 区分开

hit rate 与续势率是同一个数（1.1），所以 note §8C 的"reversal vs continuation"必须换一个**用上幅度**的操作化。唯一不重言的做法：**过度反应斜率**。

```
y_h = Σ_c [ μ_c + θ_c · log(价格冲击超过门槛的倍数) ] ,  c = 六格
H0: θ_0 = θ_1 = θ_2 且 θ_3 = θ_4 = θ_5（OI 状态不改变过度反应程度）
```

θ<0 = 冲击越大越反转（过度反应），θ>0 = 冲击越大越续势。实测（winsorized 超额 24h 收益，full）：

| 格 | θ（pp / 每单位 log 超阈倍数） | t |
|---|---|---|
| 价升 OI 降 | −0.270 | −5.07 |
| 价升 OI 安静 | −0.127 | −4.73 |
| 价升 OI 升 | **−0.385** | −6.91 |
| 价降 OI 降 | +0.122 | +3.39 |
| 价降 OI 安静 | +0.069 | +2.62 |
| 价降 OI 升 | **+0.289** | +3.81 |

等斜率检验：χ²(5 df) = **69.7**（full）、12.4（headline）；分价格符号 2 df：65.1 / 20.9。

读法：涨得越多越反转、跌得越多越反弹（两侧过度反应），**而 OI 也极端时过度反应幅度更大**（0.13→0.39，0.07→0.29）。这是一个不含符号守恒问题的、方向一致、跨样本可复现的结论，而且它和 4.2 的波动结论指向同一个机制：OI 极端 = 杠杆更拥挤 = 二阶矩更大、路径更剧烈。**它比 32 个格均值加起来信息量大。**

### 4.4 三个统计问题，现在都没处理

1. **市场因子没中性化。** 四格原始均值 0.19%–0.30% 全部是同一个市场漂移；扣除同时刻横截面均值后是 −0.04% ~ +0.12%。六个格子里"高波动市场"占比差 8 个百分点，所以原始均值之间的差有一部分只是"事件发生在什么市场环境里"。→ **原始与市场中性必须并排报，并指定一个为正式估计量**（我的建议：指定市场中性为正式，原始作为"绝对收益"面板；因为 D5 仪表盘是逐合约信号，不是择时信号）。
2. **重叠窗口。** 实测：**99.3% 的事件在同一合约 ±24h 内还有另一个事件，同一合约相邻事件的中位间隔是 2 小时**。24h 前向窗口因此大面积重叠，923,235 个事件的"有效样本"远小于名义值。现在的双向聚类（决策时刻 × 合约）在合约维度上对时间求和，实际上吸收了一部分序列相关，但不完整。→ 必须加一个"合约 × 时间块的第三维聚类"或 Driscoll–Kraay（滞后 = h）作为硬闸门，并报有效样本。我试了按"合约 × 周"聚类：收益方程的 OI 块 χ² 从 20.6 升到 28.2（不改变结论），波动方程从 1440 升到 3124（更显著）——但这个方向是保守的，必须在报告里被正面处理，不能被审稿人先发现。
3. **"不显著 = null 成立"是 accept-the-null 谬误。** 必须做等价性表述。现成的数字：原始空间 `g` 在 h=24 的 MDE(80%) = 2.802×SE = **0.238pp**（full）、**0.387pp**（headline）。也就是说现在的 `g` 检验**连 24bp 的交互都判不掉**，它既不能拒 null 也不能立 null，是彻底的无效设计。而 winsorized 的市场中性交互，95% CI 只有 **±3.2bp**（full）/ ±4.3bp（headline）。→ 这直接决定 §6 的统计量选择。

## 5. 多重检验的家族怎么切

现在把 32 个均值检验放一个家族，是**切错了维度**：家族不该按"表格的格子"切，该按"要下的一句结论"切。

三条原则：

1. **一个家族 = 一句会说出口的结论。** 描述表不进家族；稳健性表不进家族；只有"这句话是不是成立"才进。
2. **null 是合取命题**（"returns、volatility、reversal 三者都没有改进"），所以三个条款是一个 **FWER 家族**——只要任一被拒，null 就被推翻，因此必须控制"至少误拒一次"的概率。**用 Holm。**
3. **同一个条款内部**（前向期 × 样本 × 频率）是同一句话的不同分辨率，用 **BH（FDR）**，而且不该铺满：**前向期去 2 个（h=1 与 h=24）**——h=1/4/8/24 是同一路径上的嵌套窗口，同一批事件，正相依，全放进去不增加信息只增加篇幅；**频率只用 1h 正式，其余只做稳健性**（换频率只是换决策时刻，不是新样本）；**样本只用一个正式**（建议 headline，因为它是可交易域；full 作稳健性）。

最终家族结构：

| 家族 | 成员 | 校正 | 用途 |
|---|---|---|---|
| **F-confirm** | T1、T2、T3（3 个检验，h=24，headline，1h） | **Holm，α=5%** | 全局判定：null 判掉 / 判成立 |
| F-loc | T1 在 {h=1, h=24} × {headline, full} = 4 个 | BH | 表内报 q 值 |
| F-vol | T2 同上 | BH | 表内报 q 值 |
| F-rev | T3 同上 | BH | 表内报 q 值 |
| 不进家族 | D1–D5、门槛扫描、频率、波动状态分档、by_symbol | — | 只描述，不写"显著" |

一句话：**32 → 3（FWER）→ 每条款内 4（FDR）。**

## 6. 最终建议：留这 3 个检验

### 公共设定（三条，先钉死，之后不许改）

- **正式样本**：headline（当月流动性前 50 内 256,079 事件）；full 只作稳健性。
- **正式频率与前向期**：1h 标签，**h=24** 为主（note 的"短期"主张最有经济含义、且波动检验需要长窗口），h=1 为第二分辨率。
- **正式统计量**：市场中性（按同一小时横截面均值扣除）的收益，**在 h 内对 `fwd` 做 1%/99% winsorize**；波动用 `log rv`。原始均值与中位数并排报，但**不进判定**。
  （理由见 1.2 与 4.4.3：只有这个统计量的精度足以在 10bp 的经济界限上做等价性陈述；原始空间 `g` 的 95% CI 是 ±16.6bp，既判不掉也立不住。）

### T1 · 收益的"位置"

> **H0（一句话）**：给定价格冲击的方向与大小，OI 的方向、OI 是否极端、以及这两者与价格方向的交互，对事件后 24 小时的市场中性前向收益没有解释力——即四个 OI 相关系数联合为零。

- 模型：§4.1 的 6 格饱和模型 + 价格冲击十分位虚拟变量。
- 统计量：**χ²(4 df)** = {q, q², P·q, P·q²} 联合；同时报 **χ²(2)** = {q, q²}（"OI 维度"）与 **χ²(2)** = {P·q, P·q²}（"四格结构"）。
- 判定：
  - χ²(4) 在 Holm 后不拒 **且** 4 个系数的 95% CI 全部落在 ±10bp 内 → **判成立**（写成"可以排除 24h 方向收益上超过 10bp 的四状态效应"，不写"没有效应"）。
  - χ²(4) 在 Holm 后拒，但点估计 \|·\| < 10bp → 写**"统计可检出、经济不可交易"**，不算"有增量"。
  - χ²(4) 被拒且 \|·\| ≥ 10bp → null 被推翻（这条我看不到可能的来源）。
  - 额外面板（必报）：把结果变量换成 `P(fwd24 > 截面 p90)` 跑同一个 4 df 块。**若位置面板为零而尾面板非零，结论只能写成"状态影响收益分布的尾部，不影响位置"**——这正是 1.2 显示的事实。
- 我实测：χ²(4)=20.6（full）/ 11.4（headline），交互项的 95% CI = ±3.2bp / ±4.3bp → **等价性成立**，位置上的四状态效应小于成本的一半。

### T2 · 波动

> **H0（一句话）**：给定价格冲击的大小、合约与决策时点，OI 的方向、OI 是否极端、以及两者与价格方向的交互，对事件后 24 小时的已实现波动没有增量解释力。

- 模型：同 6 格 + 价格冲击十分位 + 时点 FE + 合约 FE；结果变量 `log rv24`。
- 统计量：χ²(4 df)（同 T1 的 2+2 分解）。
- 判定：χ²(4) 被拒 **且** q² 的系数 ≥ 2%（约 0.02 log 点，即相对波动 +2%）→ 判 null 的这一条**被推翻**，结论写成"JOINT 状态是波动状态"。
- 我实测：χ²(4)=1440 / 609 / 1165（三种 FE 规格），q² = +0.05 ~ +0.065（+5%~+6.5% 波动）→ **必然被拒，且不受任何合理规格影响。**

### T3 · 反转的程度

> **H0（一句话）**：价格冲击幅度对事件后收益的斜率（过度反应程度）不随 OI 的方向与是否极端改变。

- 模型：`y = Σ_c [μ_c + θ_c·log(超过门槛倍数)]`；统计量 = θ 在六格间相等的 χ²(5 df)（分价格符号报 2 df）。
- 判定：被拒即说明 OI 状态影响过度反应幅度。**"方向"不由这个检验定**（θ 的符号由数据给，不预设 note 的故事）。
- 我实测：χ²(5)=69.7（full）/ 12.4（headline）→ 被拒；θ 在 OI 极端格更大（涨侧 −0.39 vs −0.13，跌侧 +0.29 vs +0.07）。

### 这三条跑完会得到什么

| 条款 | 预期结果 | 写成什么 |
|---|---|---|
| 位置（T1） | 等价性成立（\|效应\| < 5bp） | 四状态对方向没有可交易信息 |
| 波动（T2） | 强拒 | **四状态是波动状态**：OI 极端使未来 24h 已实现波动高 5%–6.5% |
| 反转（T3） | 拒 | OI 极端时过度反应更强 |
| 四格交互（T1/T2 的 2 df 交互块） | T1 里 ~0（±3bp）；T2 里 +1.2%（χ²≈300，但只有主效应的 1/5） | **四状态框架的全部内容——"组合比两项相加更多"——在收益上没有、在波动上只有 1% 量级** |

所以对 note 那句话的正确回答是：**null 在"volatility"这一条被推翻，在"returns"与"reversal 的方向"两条成立；而"四状态"作为一个分类法（交互）在三条上都不成立——真正有用的是 OI 这个维度本身（可加的两件事：价格 + OI），不是四格的组合。**

## 7. 如果只留三句话给导师

1. 四种状态里，"价格方向"和"OI 方向/极端程度"是两个**可加**的因素；四格之间的**交互**（这才是一个新分类法该有的内容）在收益上是 0（95% CI ±3bp），在波动上只有 1% 量级。
2. 唯一又大又稳的结论是**二阶矩**：OI 也极端的事件，未来 24h 已实现波动高 5%–6.5%，且过度反应幅度大 2–3 倍。note §8B 这一条可以正面写。
3. 现在所有基于"24h 均值"的说法（R1 +0.22%、R4 最高、事件 vs 随机 +0.156pp、16/16 负 IC）在统计上是同一个尾部现象，删掉 2% 的事件就整体反转。**在任何表格定稿之前，先把统计量钉死在"市场中性 + 1% winsorize"上。**
