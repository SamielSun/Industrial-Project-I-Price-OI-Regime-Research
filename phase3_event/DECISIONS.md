## 2026-10-26 · 前向面板建成后

### D1. 前向面板分 58 个分区（不是 57）—— 保留

分区键是 `ts_end` 的年月。标签表最大 `ts_end` = 2026-09-01 00:00（最后一根 bar 的收盘时刻），
落进"2026-09"这个只有 1 小时的分区。

**决定**：保留 58 个。理由：分区键应与时间戳一致；为凑 57 而写一条"最后一小时归属上月"的
特殊规则，以后每次读分区都要记得它。代价是多一个 4 MB 的文件。

### D2. `pool_1h` 不落盘——需要时现拼

"纯价格 / 纯 OI"基准与随机时点抽样都要在 7,010,789 个 `ok` 行上取数。

**决定**：不写 `pool_1h.parquet`（约 0.9 GB），改为 `event_study.py` 需要时从标签表 + 前向面板
现拼（约 30 秒）。

**代价**：反复跑实验 6 时每次都要等 30 秒。**好处**：少存 0.9 GB，且不会出现"池子副本过期"
这种问题。

### D3. 不报时间加权均值 `mean_fm` —— 砍掉

原设计每格报两个均值：事件加权（每个事件一票）和时间加权（每小时一票）。时间加权是自加的，
note 与 brief 都没要求。

**决定**：只报事件加权均值 + 中位数 + 双向聚类标准误。时间加权口径取消。

### D4. 4h / 8h / 1d 的前向面板——等 1h 全链路跑通再建

三套逻辑相同、各约 15 秒。

**决定**：先用 1h 把 b4 → event_study 整条链验一遍，再批量补另外三个频率，避免口径返工四遍。

### D5. 随机时点抽样：层内无放回，跑 1000 轮 —— 已定

**分层 = （合约 × 市场波动状态），不按 regime 再拆。** 一层的"池子" = 该合约在该状态下所有可用的小时；
一层要替换的事件数 n = 该层里 R1–R4 的事件合计数。事件是池子的子集，所以池子恒 ≥ n。

实测（headline）：786 层，池子 ÷ 事件数的中位数 **9.15 倍**，5% 分位 4.68 倍；低于 2 倍只有 3 层，
恰好等于 1 倍的 1 层（抽出来即原样本，按用户要求不特别注明）。

**决定**：每轮从每层池子里不重复地抽 n 个时刻（给该层的事件换上）；重复 **1000 轮**，每轮产出一个统计量，
报表取中位数与 [p5, p95]。全样本（full）的池子 = 全部 ok 行，同样处理。

为什么 1000 轮：要报 5% / 95% 分位，B=1000 时这两个分位本身的抽样误差约 ±0.7 个百分点；B=200 时约
±1.5 个百分点，与区间本身宽度同量级，太糙。成本实测可接受（1h、两样本合计约 20 秒）。

## 2026-10-27 · D14（修订 D13 的推断基准）

接口评审用实测推翻了 D13 里的推断设定。**D13 的统计量与样本冻结不变，只改推断方法与三处口径。**

### 14.1 推断基准：双向聚类，删除 block bootstrap

评审实测（headline, h=24）：

| 维度 | SE 相对 iid 的放大 |
|---|---|
| 小时维度的序列相关（中性化后） | lag1 0.066 → **lag24 0.001** |
| 48h block bootstrap | **1.04×**（中性）/ 2.08×（原始） |
| **按合约聚类** | 1.35×（中性） |
| **双向聚类（时刻 × 合约）** | **1.40×** |

**决定**：主统计量用**双向聚类（时刻 × 合约）**，**不再做 block bootstrap**。

理由：造成小时维度相关的就是共同因子，市场中性化把它一起去掉了。中性化之后 block bootstrap
只把 SE 放大 4%——买不到任何东西，却要多一层复杂度。真正剩下的是**合约维度**（1.35×），
而 block bootstrap 抓不到它。

⚠️ **仅对原始（未中性化）收益成立**：那里 block bootstrap 会把 t 从 3.96 打到 1.90。
所以**报告里凡是出现原始收益的地方，都必须换成按小时聚类的标准误，或干脆不报推断**。

**中位数例外**：中位数没有解析标准误，仍需重抽。用**按小时有放回重抽**（i.i.d. 小时，不切块），
因为中性化后小时维度的相关已可忽略。

### 14.2 单位冻结

内部一律用**小数**（`fwd_24h = 0.002235`）。**等价界限 10bp = 0.0010（小数）**。
所有表格输出成**百分数**（+0.2235%）。任何把 10 与小数系数相比的写法都是 bug，且不会报错。

### 14.3 截尾阈值取全市场 pool，不取格内

按格内截尾会让 R1−R4 的 DiD **变号**（不压 +2.30bp / 全样本压 −1.74bp / 格内压 +0.78bp，跨方案差 4bp = 等价界限的 40%）。
**冻结**：阈值在全市场 pool（7,010,789 行）上算一次，所有格、所有对照行共用同一组阈值。

⚠️ 由此产生两个必须在报告里写的事实：
- 全样本截尾本身就让 R1−R4 从 **+2.30bp 变成 −1.74bp**——均值效应基本活在尾部
- h=24 时事件行有 4.53% 被压（不是名义的 2%），因为事件分布比 pool 更肥尾

### 14.4 实验 3/4 用四格，不用六格

事件子样本里 OI 全部"极端"，六格设计矩阵**秩只有 4**（`q²≡1`、`P·q²≡P`），lstsq 会静默返回最小范数解。
**实验 3（波动）与实验 4（反转斜率）只用四格**（const, P, q, Pq，q ∈ {−1,+1}）。
**只有实验 1（含 OI 安静对照）才用六格**——那里 q 才有 0 这一档。

### 14.5 所有推断函数返回重抽分布，不返回标量 SE

4 维联合区间、χ²(5) 都要用协方差，标量 SE 拼不出来。

区间和 SE 照常报，但不再做"可排除超过 N bp"这类声明。

**同时删掉 D13 里的"等价界限 10bp"这一项**——不再需要。

### 15.3 反转斜率在冻结口径下无差别

冻结口径下构造不出来——**不能拿 69.7 当验收目标**。
