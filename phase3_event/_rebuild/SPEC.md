## 零、全局约定（写进代码前先读）

| 项 | 值 | 说明 |
|---|---|---|
| 内部单位 | **小数** | `fwd_24h = 0.002235`。输出表转百分数 |
| 去均值基 | **全市场 ok 池 7,010,789 行** | 每小时约 **174 个合约**。只用事件行去均值是错的（每小时 7.1 个），两种做法的 DiD 差 44% |
| 截尾阈值 | **全 pool 算一次，所有格共用** | 禁止按格内算：会让 DiD 变号（+2.30 → −1.74 → +0.78bp） |
| 推断 | **只按合约聚类**（\`cluster_se\`）| 中性化后小时维度 lag24 自相关只有 0.001，block bootstrap 只放大 1.04×，买不到东西；真正剩下的是合约维度（1.35×），它抓不到 |
| 重抽共享 | 只有中位数需要重抽；`(reps, seed)` **全局抽一次**，所有格子复用 | 否则均值与中位数的"符号矛盾"里会混进不同抽样噪声 |
| 小时编码 | `hour = (ts_end − 2021-12-01) / 1h`，整数 | 前向面板**没有** hour 列，必须现算。两套编码混用会 0 行匹配且不报错 |
| 读分区 | 逐文件 `pd.read_parquet` | `pq.read_table` 会因目录 `freq=1h` 与文件内 `freq` 列冲突抛 ArrowTypeError |
| 环境 | **没有 scipy / statsmodels** | χ² 的生存函数要自己实现（见第 5 节） |

## 一、stats_core.py 接口（重写）

### 1.1 去均值与截尾

```
cross_sectional_demean(df, value_col, hour_col="hour", out_col="excess") -> (df, n_per_hour)
    在【全 pool】上逐小时减等权均值；n_per_hour 是该 pool 每小时的合约数
    验收：n_per_hour 的中位数必须 ≈ 174（不是 7）；组均值 0 是定义，不算验收

winsorize(values, lower, upper, thresholds=None) -> (ndarray, (lo, hi))
    阈值可由外部传入（全 pool 算的那组），返回压平后的值与阈值
    **没有 by 参数**——按格内压会让 DiD 变成截尾规则的函数
    验收：换一组阈值重算，DiD 变化 ≤ 0.5bp
```

### 1.2 推断

**均值与 OLS：解析双向聚类，不重抽。**

\`\`\`
cluster_se(X, y, symbol_codes) -> (b, V)
    V = V_hour + V_symbol − V_intersection（CGM）
    验收：与独立实现的按 symbol 聚类协方差在 block 意义上一致；
          给同一小时所有合约加公共冲击时，V_hour 必须随之增大（说明小时内相关被算进去）
\`\`\`

**中位数：按小时有放回重抽（不切块）。**

\`\`\`
cell_medians_boot(df, value_col, group_col, hour_col, reps, seed) -> (reps, n_groups)
    每次重抽：有放回抽 hour，把被抽中小时的所有行整体带走，重算每格中位数
    返回 (reps, 格数) 的分布，调用方自己组合成"差的中学数"或"配对中位数"
    验收：给【全体】每个值加同一常数 → 方差不变（1e-12）；给【同一小时】所有合约加公共冲击 → 方差必须变
          全量 1000 次 ≤ 10 秒
\`\`\`

### 1.3 设计矩阵

```
four_cell_design(df, ...) -> (X, names)      # const, P, q, Pq   （q ∈ {−1,+1}）
six_cell_design(df, ...) -> (X, names)       # const, P, q, q2, Pq, Pq2（q ∈ {−1,0,+1}）

两者都要：
- 断言 `np.linalg.matrix_rank(X) == X.shape[1]`，秩亏直接抛 ValueError
- 断言域：six_cell 要求同时存在 q=0 与 q=±1；four_cell 要求 q ∈ {−1,+1}
- 输出 names 后，调用方按名字取系数，不按下标
```

**为什么必须分开**：事件子样本里 OI 全是极端，`q² ≡ 1`、`P·q² ≡ P`，六格矩阵**秩只有 4**。
实验 3（波动）与实验 4（反转斜率）**只能用四格**；只有实验 1（含 OI 安静对照）能用六格。

### 1.4 中位数

按**小时**有放回重抽（不切块——中性化后小时维度相关已可忽略）：

```
cell_medians_boot(df, value_col, group_col, hour_col, reps, seed) -> (reps, n_groups)
```

每次重抽：有放回抽 hour，把被抽中小时的所有行整体带走，重算每格中位数。
返回 (reps, 格数) 的分布；调用方自己组合成"差的中学数"或"配对中位数"，**并在表注写明用的是哪一种**——它们是不同的估计量。

验收三条：① 全体加常数 → 方差不变（1e-12）；② 同一小时加公共冲击 → 方差必须变（实测 10.7 倍）；
③ 整小时带走的 sd 必须是按行重抽的 > 2 倍（实测 2.8–2.9×）。全量 1000 次 ≤ 10 秒。

## 三、四个确认性检验的接口

| 检验 | 样本 | 设计 | 因变量 | 统计量 |
|---|---|---|---|---|
| 1 收益·均值 | headline 事件 + 价格超阈/OI 安静对照 | **六格** + log(shock) 控制 | `winsor_fwd_24h` | 4 维 Wald；等价性写在格子对比上 |
| 2 收益·中位数 | 同上 | **六格** | `winsor_fwd_24h` | 格子中位数的 DiD，重抽分布 |
| 3 波动 | headline 事件 | **四格，不加固定效应**（D15.1） | `log(rv_24h)` | χ²(3)：P、q、Pq 三个系数 |
| 4 反转斜率 | headline 事件 | 见 3.1 的参数化 | `winsor_fwd_24h` | 斜率相等的 χ²(**3**)（4 条斜率 → 3 个约束）|

**判定用普通显著性**：Wald 的 p 值 < 0.05 即认为有增量；不显著就写"测不出增量"。
不再做等价性检验（不做"可排除超过 N bp"的声明）。

**联合检验**：`W = b' V⁻¹ b`，V 取自同一组重抽的协方差。**严禁把两个 t² 相加**（等于假设协方差为 0）。

### 3.1 实验 4 的参数化（"四条斜率相等"）

`wald_test` 只能表达"某些系数为 0"。检验斜率相等必须先重参数化：

```
X = [mu_R1, mu_R2, mu_R3, mu_R4, ls, D2·ls, D3·ls, D4·ls]
```

`ls = log(shock)`，`Dk·ls = 1{第 k 格}·ls`。公共斜率是 `ls`，三个偏差是后三列。
"H0: 四条斜率相等" = `wald_test(b, V, [5, 6, 7])`，df = **3**。

用 4 格各一条斜率的 8 参模型直接挑 4 个下标会算错（实测 W = 3.26 vs 正确的 2.475）。

## 四、闸门（v2 替换 v1 的全部验收）

| 闸门 | 判据 | 为什么这条能失败 |
|---|---|---|
| 去均值基 | `n_per_hour` 中位数 ∈ [150, 200] | 用事件子样本会得到 7.1，一秒钟抓出 |
| 截尾口径 | 换一组阈值，DiD 变化 ≤ 0.5bp | 按格内压会得到 2.5–4bp |
| 重抽保相关 | 给同一小时加公共冲击，boot 方差必须变（实测 10.7×）；整小时 sd > 按行重抽的 2 倍 | 按行重抽不会变 |
| 设计矩阵秩 | `rank(X) == ncol` | 六格用在事件样本上会得到 4 |
| 单位 | 点估计量级：`abs(mean(winsor_fwd_24h)) < 0.05`（小数） | 若误写百分数会 > 0.05 |
| 中位数 | 全量 1000 次重抽 ≤ 10 秒 | 超过说明在逐行重抽 |

## 五、环境补丁（实现者必看）

1. **没有 scipy**。χ² 生存函数自己写：`Q(k/2, x/2)` 用正则化下不完全伽马（连分式 + 级数，Numerical Recipes 6.2），
   自检：`chi2_sf(2, x) == exp(-x/2)`（1e-12）、`chi2_sf(4, 9.49) ≈ 0.05`（1e-4）。
2. **两套 hour 编码**：事件表的 `hour` 原点 2021-12-01；前向面板没有 hour 列，必须用 `ts_end` 现算。
   上线前先做一次匹配断言：按 hour join 后行数必须等于事件数，**不许静默返回 0 行**。
3. **分区读取**：用 `pd.read_parquet(单个文件)`，不要 `pq.read_table(分区目录)`。
4. **float32**：`fwd_*` 是 float32，去均值/截尾前先转 float64，否则残差在 2e-8 量级，
   任何 1e-12 的断言都会假失败。
