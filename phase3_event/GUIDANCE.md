---
**三条为什么必须这么定**
- 不减市场因子：headline 口径下 R4 的 h=24 均值是 **+0.250%**，而它的市场中性值是 **−0.048%**，
  也就是说原始收益里那点正数全部来自共同因子（`descriptive_core` 的 `mean_raw` / `mean_excess`）
- 截尾**不是中性变换**：h=1 时 R1 的事件被压 3.36%、同向池子只压 1.34%，一刀下去砍事件砍得更多，
  会让均值的差缩小甚至变号。所以主口径不截尾，极端值的影响靠中位数和 `t_drop5` 兜
- 不聚类 t 会虚高：同一合约的序列相关、同一时刻的横截面相关，两层都会把标准误算小

# 一、判定层（实验 1–9）

## 1. 收益 · 均值
**表**：`tables/freq=1h/exp1_4.parquet`（`experiment = "1 收益·均值"`）
**样本**：headline、`excl_reason == ok`、`ok_{h}h`、**全部价格超阈的行**（h=24：事件 255,807 +
OI 安静 298,682 = **554,489** 行）。
**做法**：每个状态单独比。**样本**是同向价格超阈的全部行（自然包含该状态自己的行，
否则估不出固定效应），但**比较组是该状态之外的那些行**——回归里 dummy=1 vs dummy=0，
所以 β 是「状态 vs 其余行」的干净对照，不是被自己稀释过的差：

| 状态 | 同向样本 | 比较组（dummy=0）|
|---|---|---|
| R1 / R2 | 价格超阈上涨的全部行 | 其中的**其他行**（另一个状态 + OI 安静行）|
| R3 / R4 | 价格超阈下跌的全部行 | 其中的**其他行**（另一个状态 + OI 安静行）|

全部 headline 样本**一起估一个 β**（不是分组各跑一次）；因为币和月份的水平已经被固定效应扣掉，
所以这一比较的参照系是「同一个币、同一个月」。
**估计步骤**：

```
步骤一 · 回归公式
  y_it = β·D_it + Σ_{i=1}^{249} α_i·1(contract = i) + Σ_{t=1}^{54} λ_t·1(month = t) + ε_it
  · i = 第几个合约（共 249 个），例如 BTCUSDT、ETHUSDT
  · t = 第几个月（共 54 个），2022-03 … 2026-08；一行 = 某个合约的某一个小时
  · y_it：市场中性收益（y_raw）
  · D_it：这一行是 R1 取 1，是基准取 0
  · α_i：第 i 个合约的水平（合约固定效应）；λ_t：第 t 个月的水平（月份固定效应）
  · 1(contract = i)、1(month = t)：指示函数，这一行属于哪个合约 / 哪个月就取 1，其余取 0
  · β：标签相对「同向超阈行的其余行」的超额（dummy=0 组 = 另一个 OI 状态 + OI 安静行）
步骤二 · β
  回归拟合出 β，就是表里的 estimate。
  代码为了速度不把 303 个虚拟变量放进矩阵，而是把 y 和 0/1 标记按同样分组双向去均值到
  <1e-7（实测 15 轮），再在残差上回归；得到的 β 与直接回归完全相同。
步骤三 · SE 和 t
  û = ỹ − β · x̃
  ψ = x̃ · û
  V = Σ_合约(Σψ)² + Σ_月份(Σψ)² − Σ_合约月(Σψ)²
  SE = √V / Σ x̃²
  t = β / SE
```

**统计量**：另报 `p_bh`（16 格 BH）与 `t_drop5`（剔贡献最大的 5 个合约后重估）。
**结果**（bp，括号内 t / p_bh / t_drop5）：

| | h=1 | h=4 | h=8 | h=24 |
|---|---|---|---|---|
| R1 | **+2.51bp (+3.41 / 0.0100 / +2.34)** | +1.84bp (+1.01 / 0.3310 / +0.24) | +3.22bp (+1.35 / 0.2569 / +0.59) | +5.06bp (+1.48 / 0.2237 / +0.10) |
| R2 | -1.09bp (-1.75 / 0.1607 / -1.80) | -1.67bp (-1.13 / 0.3042 / -1.52) | -3.28bp (-1.56 / 0.2099 / -1.90) | **-7.12bp (-2.50 / 0.0399 / -2.26)** |
| R3 | -0.87bp (-1.16 / 0.3042 / -1.86) | **-4.39bp (-3.02 / 0.0133 / -2.13)** | **-8.26bp (-3.23 / 0.0100 / -3.47)** | **-11.63bp (-2.61 / 0.0357 / -2.21)** |
| R4 | +0.25bp (+0.52 / 0.6012 / +0.24) | **+2.05bp (+2.43 / 0.0406 / +2.29)** | +2.55bp (+1.89 / 0.1338 / +2.03) | +3.52bp (+1.11 / 0.3042 / +1.07) |

`p_bh`：通过的 6 格全部 < 0.05（最小 0.0100，R3@8h）；`t_drop5` 同号同量级
（R3@8h −3.47 最强，R1@1h +2.34）。
**判定**：6/16 格过 \|t\| > 1.96 —— R1@1h、R3@4h、R3@8h、R3@24h、R2@24h、R4@4h。

### 附 1b · 2×2 因子：OI 增量、价格增量、交互
**表**：`tables/freq=1h/exp1_4.parquet`（`experiment = "1b 因子对比"`，20 行 = 5 个对比 × 4 期限）
**样本**：headline、`excl_reason == ok`、`ok_{h}h`、**只取 cell 1–4**（剔除 OI 安静的 cell 0）：
h=1 时 **256,076** 行（R1 74,959 + R2 50,564 + R3 44,622 + R4 85,931），h=24 时 255,807 行。
**做法**：四个状态本来就是 `价格(涨/跌) × OI(增/减)` 的 2×2 因子。设
`P = 1{涨}`（R1/R2）、`O = 1{OI 增}`（R1/R3），在四个格子上做一套回归，
五个要报的量都是系数的线性组合 `e'β`：

| 对比 | 含义 | 系数组合 |
|---|---|---|
| R1 − R2 | OI 增量，价格固定为涨 | `b + c` |
| R3 − R4 | OI 增量，价格固定为跌 | `b` |
| R1 − R3 | 价格增量，OI 固定为增 | `a + c` |
| R2 − R4 | 价格增量，OI 固定为减 | `a` |
| (R1−R2) − (R3−R4) | 交互 | `c` |

**估计步骤**：

```
步骤一 · 回归公式
  y_it = a·P_it + b·O_it + c·(P_it·O_it)
         + Σ_{i=1}^{249} α_i·1(contract = i) + Σ_{t=1}^{54} λ_t·1(month = t) + ε_it
  · y_it：市场中性收益　· P_it：这一行是涨取 1　· O_it：这一行 OI 增取 1
  · α_i、λ_t：合约、月份固定效应
  · a：OI **减**时的价格差（R2−R4）　b：价格**跌**时的 OI 差（R3−R4）
  · a+c：OI 增时的价格差（R1−R3）　b+c：价格涨时的 OI 差（R1−R2）　c：交互
步骤二 · 五个线性组合
  e'β，e 见上表；一趟回归同时出五个对比
步骤三 · SE 和 t
  û = ỹ − X̃β ；ψ = X̃·û（三列）
  V = Σ_合约(Σψ)(Σψ)' + Σ_月份(Σψ)(Σψ)' − Σ_合约月(Σψ)(Σψ)'
  SE = √( e' · bread · V · bread · e ) ，bread = (X̃'X̃)⁻¹
  t  = e'β / SE
```

**统计量**：BH 家族 = 本节 20 格（与实验 1 的 16 格家族分开）；
另报 `t_drop5`（按 `ψ·(bread·e)` 给每个合约打分，剔绝对值最大的 5 个后重估）。
**结果**（bp，括号内 t / p_bh / t_drop5；加粗 = \|t\| > 1.96）：

| | h=1 | h=4 | h=8 | h=24 |
|---|---|---|---|---|
| OI\|价格上 (R1-R2) | **+2.83bp (+3.40 / 0.0032 / +3.57)** | +2.11bp (+0.95 / 0.3804 / +0.36) | +3.96bp (+1.28 / 0.2511 / +1.70) | **+8.35bp (+2.24 / 0.0391 / +0.90)** |
| OI\|价格下 (R3-R4) | -0.62bp (-0.72 / 0.4693 / -0.68) | **-4.70bp (-3.18 / 0.0049 / -2.85)** | **-8.25bp (-3.53 / 0.0028 / -4.59)** | **-12.31bp (-2.49 / 0.0233 / -2.30)** |
| 价格\|OI增 (R1-R3) | +0.92bp (+0.74 / 0.4693 / +0.69) | +2.94bp (+1.08 / 0.3271 / +0.42) | +6.38bp (+1.87 / 0.0815 / +1.07) | **+11.18bp (+2.22 / 0.0391 / +2.22)** |
| 价格\|OI减 (R2-R4) | **-2.53bp (-2.90 / 0.0108 / -3.29)** | **-3.86bp (-2.21 / 0.0391 / -3.12)** | **-5.83bp (-2.68 / 0.0163 / -3.91)** | **-9.49bp (-2.57 / 0.0206 / -2.67)** |
| 交互 (R1−R2)−(R3−R4) | **+3.46bp (+3.35 / 0.0032 / +4.12)** | **+6.81bp (+2.79 / 0.0130 / +1.97)** | **+12.22bp (+4.26 / 3.2e-04 / +3.12)** | **+20.67bp (+4.16 / 3.2e-04 / +4.05)** |

**判定**：**14/20 过 \|t\| > 1.96**，BH 后仍 14/20，`t_drop5` 后 13/20。
**逐行解读**（每行 = 固定一个维度、看另一个维度；按稳健程度排）：

| 对比 | 各期限 t（h=1/4/8/24）| \|t\|>1.96 | BH 后 | drop5 后 | 读法 |
|---|---|---|---|---|---|
| R2−R4　价格增量 · OI 减 | −2.90 / −2.21 / −2.68 / −2.57 | **4/4** | 4/4 | **4/4** | OI 收缩时，跌的那个（强平）跑赢涨的那个（回补），差距随期限拉大 |
| (R1−R2)−(R3−R4)　交互 | 3.35 / 2.79 / 4.26 / 4.16 | **4/4** | 4/4 | **4/4** | OI 的作用在涨、跌两侧方向相反 |
| R3−R4　OI 增量 · 价跌 | −0.72 / −3.18 / −3.53 / −2.49 | 3/4 | 3/4 | 3/4 | h=4 两边各贡献一半；h=8/24 几乎全来自 R3 的负超额（见下）|
| R1−R2　OI 增量 · 价涨 | 3.40 / 0.95 / 1.28 / 2.24 | 2/4 | 2/4 | **1/4** | 涨的时候 OI 增更好，但只有 h=1 稳；h=24 靠少数合约 |
| R1−R3　价格增量 · OI 增 | 0.74 / 1.08 / 1.87 / 2.22 | 1/4 | 1/4 | 1/4 | OI 增时价格方向基本不带信息，只有 24h 才出现 |

**结论**：
1. **最稳的是“OI 收缩”这一整支**（R2−R4 4/4、R3−R4 3/4，BH 与 drop5 之后都还在）。
   但要注意：**差值本身不告诉你哪一侧造成的**，要回看实验 1 的两侧水平。
2. **交互是唯一“全期限 + 全稳健性”都过的结论**（4/4，连 drop5 也 4/4）：
   价格与 OI 的效应**不可加**，不能拆成两个独立因子——这是 1b 里最硬的统计事实，
   也直接构成“四状态要当作组合来看”的依据。
3. **OI 扩张时价格方向不带信息**（R1−R3 只有 h=24 过）：新仓建立之后方向本身不预测，
   要到一天尺度才显现。
4. **最不稳的是“涨 + OI 增”**（R1−R2）：h=1 的 +2.83bp 很稳，但 h=24 的 +8.35bp
   在剔除 5 个合约后掉到 t = 0.90。所以“涨的时候 OI 增更好”**只在 1 小时尺度上成立**。
**差值来源**：`1b` 只给两格之差，答不了「哪一侧造成的」；要判断就得回看实验 1 的两侧水平
（R3 相对跌的基准、R4 相对跌的基准）。结论是：h=4 两侧各贡献一半，h=8/24 几乎全来自 R3 低于基准；
而 `R2−R4` 的负差主要来自 R4 高于基准（反弹），R2 的回吐只在日尺度明显。

## 2. 收益 · 中位数（只报数，不检验）
**表**：`tables/freq=1h/exp1_4.parquet`（`experiment = "2 收益·中位数"`）
**样本**：同实验 1。
**做法**：每个合约先算一个中位数差，再跨合约平均：

```
Δ_s = median(该状态的行) − median(同向其余行)   （其余行 = 同向、价格超阈、但不是该状态）
报的数 = mean(Δ_s)            s = 1 … 249（R3 只有 248：BSBUSDT 无 R3 事件）
```

**估计步骤**：

```
步骤一 · 不去效应：每个合约单独看，既不扣币效应也不扣月效应
步骤二 · 不算回归：每个合约先算 Δ_s = median(该状态的行) − median(同向其余行)，
  再对所有合约取平均
步骤三 · 不算 SE、不算 t（不检验）
```

**统计量**：不检验（`se`/`t`/`p`/`p_bh` 全为空）；附带报 `Δ_s` 里为负的合约占比。
**结果**（bp，括号内为"Δ_s < 0 的合约占比"）：

| | h=1 | h=4 | h=8 | h=24 |
|---|---|---|---|---|
| R1 | -3.86bp (67%) | -13.07bp (75%) | -22.01bp (72%) | -66.27bp (76%) |

## 3. 波动
**表**：`tables/freq=1h/exp1_4.parquet`（`experiment = "3 波动"`）
**样本**：同实验 1——必须包含 OI 安静的 cell 0 行，否则「同向超阈行的其余行」就退化成「另一个 OI 状态」。
**做法**：四个对比与实验 1 完全相同，因变量换成 `lrv = log(rv_h)`。
**估计步骤**：

```
步骤一 · 回归公式
  y_it = β·D_it + Σ_{i=1}^{249} α_i·1(contract = i) + Σ_{t=1}^{54} λ_t·1(month = t) + ε_it
  · i = 第几个合约（共 249 个）　t = 第几个月（共 54 个）；一行 = 某个合约的某一个小时
  · y_it：已实现波动的对数（lrv = ln rv_h）
  · D_it：这一行是该状态取 1，是基准取 0
  · α_i：第 i 个合约的水平；λ_t：第 t 个月的水平；两个 1(·) 是指示函数
  · β：标签的波动比「同向超阈行的其余行」高多少（dummy=0 组；表里换算成 exp(β) − 1 的百分比）
步骤二 · β
  回归拟合出 β，就是表里的 estimate 的底数（表里报 exp(β) − 1）。
  代码为了速度不把 303 个虚拟变量放进矩阵，而是把 y 和 0/1 标记按同样分组双向去均值到
  <1e-7（实测 15 轮），再在残差上回归；得到的 β 与直接回归完全相同。
步骤三 · SE 和 t
  û = ỹ − β · x̃
  ψ = x̃ · û
  V = Σ_合约(Σψ)² + Σ_月份(Σψ)² − Σ_合约月(Σψ)²
  SE = √V / Σ x̃²
  t = β / SE
```

**统计量**：表里的数换成 `exp(β) − 1`（比基准高百分之多少）；另报 `p_bh` 与 `t_drop5`。
**结果**（比基准高 %，括号内 t / p_bh / t_drop5）：

| R2 | **+9.06% (+7.95 / 2.2e-15 / +8.51)** | **+8.09% (+8.98 / 3.6e-19 / +9.44)** | **+7.02% (+8.17 / 3.9e-16 / +8.62)** | **+5.81% (+7.00 / 2.5e-12 / +7.02)** |

| R4 | **+9.92% (+9.94 / 5.5e-23 / +10.53)** | **+7.10% (+9.93 / 5.5e-23 / +10.76)** | **+5.83% (+9.59 / 1.4e-21 / +11.03)** | **+4.33% (+7.75 / 9.9e-15 / +9.07)** |

## 4. 续势 / 反转（反转概率：状态 vs 同向超阈行的其余行）
**表**：`tables/freq=1h/rev_prob.parquet`（判定层，16 行 = 4 regime × 4 期限）；
描述性的续势/反转/无效应比例在 `descriptive_core.parquet`（`p_cont` / `p_rev` / `p_flat`）。
**样本**：headline、`excl_reason == ok`、`ok_{h}h`、**全部价格超阈的行**（含 OI 安静的 cell 0）：
h=1 时 **555,008** 行（涨 277,431 + 跌 277,577，其中 cell 0 298,932），h=24 时 554,489 行。
反转标记要用**原始前向收益** `fwd_{h}h` 的符号，所以样本由 `panel(cell 0–4)` 与
`forward/freq=1h` 按 (合约, 小时) 合并而成——事件表只有 R1–R4，不含 cell 0。
**做法**：因变量是 0/1，所以用**线性概率模型**（LPM），其余设计与实验 1/3 逐条相同：

```
rev_it = β·D_it + 两组固定效应
D_it = 1（该行属于被检验的状态）/ 0（同向价格超阈行中的其余行 = 另一个 OI 状态 + OI 安静行）
```

**估计步骤**：

```
步骤一 · 回归公式（四个状态各跑一次，样本都是该方向的全部行）
  rev_it = β·D_it + Σ_{i=1}^{249} α_i·1(contract = i) + Σ_{t=1}^{54} λ_t·1(month = t) + ε_it
  · rev_it = 1{sign(fwd_h) = −sign(price_change)}（反转 1、否则 0；0/1 用 LPM 估计）
  · D_it = 1（该状态行）/ 0（同向其余行）
  · α_i、λ_t：合约、月份固定效应
步骤二 · 估计值
  β：同一个币、同一个月内部，该状态的反转概率比「同向其余行」高多少（小数，×100 = 百分点）。
  代码先把 rev 与 D 按合约、月份双向去均值到 <1e-7，再在残差上回归；与直接回归完全相同。
步骤三 · SE 和 t
  ψ_it = D̃_it · û_it
  V = Σ_合约(Σψ)² + Σ_月份(Σψ)² − Σ_合约月(Σψ)²
  SE = √V / ΣD̃² ；t = β / SE
```

**与实验 1/3 的唯一差别**：**没有市场中性化**。0/1 因变量没有"减去市场平均"的定义——
反转看的是"前向收益的符号与事件方向是否相反"，减掉市场均值会改变符号本身，那一列就不再是反转。
**统计量**：BH 家族 = 本节 **16 格**（4 regime × 4 期限）；另报 `t_drop5`；单位是**百分点（pp）**。
**结果**（β，pp；括号内 t / p_bh / t_drop5；加粗 = \|t\| > 1.96）：

| | h=1 | h=4 | h=8 | h=24 |
|---|---|---|---|---|
| R1 | **+1.19pp (+2.81 / 0.0100 / +3.34)** | **+2.45pp (+6.26 / 2.0e-09 / +7.02)** | **+2.50pp (+6.36 / 1.6e-09 / +7.98)** | **+2.51pp (+7.29 / 4.8e-12 / +8.16)** |
| R2 | **-1.00pp (-2.56 / 0.0166 / -3.33)** | **-1.21pp (-2.69 / 0.0129 / -3.66)** | **-2.17pp (-4.09 / 1.7e-04 / -4.47)** | **-1.91pp (-3.40 / 0.0022 / -3.49)** |
| R3 | -0.18pp (-0.48 / 0.8574 / -0.74) | +0.09pp (+0.25 / 0.8574 / +0.11) | +0.04pp (+0.09 / 0.9269 / +0.14) | **+1.48pp (+3.08 / 0.0047 / +2.72)** |
| R4 | -0.10pp (-0.26 / 0.8574 / -0.58) | +0.10pp (+0.26 / 0.8574 / +0.16) | -0.14pp (-0.37 / 0.8574 / -0.51) | **-1.25pp (-3.14 / 0.0045 / -3.41)** |

描述性的续势 / 反转 / 无效应比例（h=24；四个期限的并集范围：续势 45.2%–49.8%、反转 50.0%–53.9%）：

| h=24 | 续势 | 反转 | 无效应 |
|---|---|---|---|
| R1 | 0.460 | 0.538 | 0.0017 |
| R2 | 0.485 | 0.514 | 0.0017 |
| R3 | 0.488 | 0.511 | 0.0016 |

**判定**：**10/16 过 \|t\| > 1.96**；**BH 后仍 10/16**；**drop5 后仍 10/16**（三套标准完全一致）。
**结论**：
1. **"涨"这一支 8/8 全过**：R1（涨+OI增）的反转概率比其余行**高 1.19 ~ 2.51pp**
   （h=1/4/8/24，t 2.81/6.26/6.36/7.29，BH 与 drop5 全过）；R2（涨+OI减）**低 1.00 ~ 2.17pp**

## 8. 安慰剂：regime vs 随机时刻
**表**：`tables/freq=1h/placebo.parquet`（16 行 = 4 regime × 4 期限）；脚本 `phase3_event/experiment/exp8_placebo.py`。
**样本**：真实值用该 regime 的 headline 事件行（h=1 时 R1 74,959 / R2 50,564 / R3 44,622 / R4 85,931）；
随机池用**同一批合约的全部小时**（panel，h=1 共 1,966,709 行，含 cell 0 与 −1）。
**做法**：每个 regime 的合约构成保持不变，把时刻换成随机小时：

```
真实值   = mean(y_raw | 该 regime 的所有行)
随机分布 = 1000 轮，每轮在**同一批合约的全部小时**里均匀抽同样数量的时刻，
           算同样的均值（抽到的小时不管价格/OI 动没动、是什么 cell）
```

**估计步骤**：

```
步骤一 · 抽随机时刻
  对 regime k 的每一行，记下它的合约 c；在 c 的全部小时里均匀抽一个小时。
  不要求价格超阈、不要求 OI 超阈——"随机"就是什么都不管。
步骤二 · 估计值
  真实值 = mean(y_raw | regime k)；每轮得到 mean(y_raw | 抽到的行)；
  1000 轮构成随机分布。
步骤三 · 经验 p
  p_placebo = 2 × min(P(随机 ≤ 真实), P(随机 ≥ 真实))，上限 1。
  1000 轮的分辨率是 0.002；σ 未估、不做 t、不进任何 BH 家族。
  种子 = config.EVENT.random_seed + h，轮数 = config.EVENT.random_draws（= 1000），
  所以任何机器重跑都得到完全相同的分布（实测连跑两次，数值哈希一致）。
```

**统计量**：随机分布的 p5 / p50 / p95 与双侧经验 p；单位 **bp**。
**结果**（真实值 [随机 p5, p95]，单位 bp；加粗 = 落在随机区间之外）：

| | h=1 | h=4 | h=8 | h=24 |

| R1 | **+0.70 [-0.70, +0.36] 高于随机 p95** | -0.84 [-1.78, +0.21] 落在随机区间内 | -1.15 [-2.95, -0.00] 落在随机区间内 | -3.26 [-6.88, -1.87] 落在随机区间内 |
| R2 | **-2.30 [-0.89, +0.52] 低于随机 p5** | **-3.90 [-2.27, +0.36] 低于随机 p5** | **-6.67 [-3.61, +0.06] 低于随机 p5** | **-13.70 [-8.58, -1.81] 低于随机 p5** |
| R3 | -0.57 [-1.02, +0.46] 落在随机区间内 | **-5.91 [-2.64, +0.26] 低于随机 p5** | **-11.31 [-4.54, -0.41] 低于随机 p5** | **-20.51 [-10.21, -3.22] 低于随机 p5** |

**图上**：Fig 8 每个 regime 一个面板，灰带 = 1,000 轮随机时刻的 [p5, p95]，横杠 = 中位，实心点 = 落在带外。

**判定**：**10/16 落在随机区间之外**——R2 四个期限全部低于 p5、R3 在 h=4/8/24 低于 p5、R1 只有 h=1 高于 p95、R4 只有 h=4/8 高于 p95；R1 与 R4 在 h=24 都落回区间内。
**结论**：

3. **"时刻是否特殊"和"是否显著"是两件事**：实验 1 里 R4 的 β 只有 h=4 显著，
   但安慰剂显示它在 h=4/8 都高于随机时刻；反过来 R1 的 β 在 h=4/8/24 都不显著，
   安慰剂在 h=1 却指向"高于随机"。两者回答的问题不同：β 是"比同类事件"，安慰剂是"比随便什么时候"。
4. **本节只做收益，不做反转**：反转概率在随机时刻上**没有定义**——随机抽到的小时里约 71%
   是价格根本没超阈的行（cell −1），谈不上"反转"。反转的对照看实验 4 的基准
   （同一批真实事件里的其余行），那才是可比的参照。

## 9. 四条信号并排 + 四状态 vs 基线
> 「**四状态**」= 状态标签自己的多空组合（**R1 多头 / R4 空头**）。
> 它的**水平**画在 **Fig 5-7 的第 4 个面板**（与三条基线同一池化口径、同一估计量、同一 CGM SE）；
> **Fig 9 只放它与三条基线的同日 Δ**（日频等权、Newey-West）。两张图不再混口径。

**表**：`tables/freq=1h/exp5_9.parquet`（`experiment = "9 逐日价差"` 与 `"9 Δ"`）
**样本**：四条信号（纯价格 / 纯 OI / 纯 funding / 四状态），同一批 **710–711 天**（交集）。
**做法**：

```
时段 = 自然日（24 小时，UTC 00:00 对齐）
每天每个信号：r_k(t) = 当天多头组收益均值 − 空头组均值
             要求每边 ≥5 个不同合约，否则该天该信号缺失

Δ_k = r̄_四状态 − r̄_k        k = 纯价格 / 纯 OI / 纯 funding
标准误：Newey-West，滞后 = max(1, h/24) = 1
```

**估计步骤**：

```
步骤一 · 不做回归
  按自然日算：每天每信号 r_k = 当天多组均值 − 空组均值（每边至少 5 个合约），

## 15. 日频汇总稳健性（note 的 "Daily aggregation for robustness"）
**表**：`tables/freq=1h/robust_daily.parquet` 与 `robust_daily_bycount.parquet`
**样本**：与实验 1/3 **完全同一批行**（headline、`ok_{h}h`、`dir != 0`）。
**做法**：只换观测单位——按 (symbol, day, dir, cell) 聚成组，`day = hour // 24`（UTC 自然日），
组内对因变量取均值；然后**原样重跑**实验 1 与实验 3 的检验（合约 + 月份双向 FE、双向聚类、
基准/比较组 = 其中 dummy=0 的行）。`dir` 必须进聚合键，因为 `cell == 0` 同一天里既有涨也有跌的行。
**估计步骤**：

```
步骤一 · 回归公式（观测单位是「合约 × 自然日 × 格」）
  y_idk = β·D_idk + Σ_{i=1}^{249} α_i·1(contract = i) + Σ_{t=1}^{54} λ_t·1(month = t) + ε_idk
  · i = 第几个合约（共 249 个）
  · d = 第几个自然日（UTC，距 2021-12-01 的天数）
  · k = 这一格是哪个方向 × 哪个格（涨/跌 × R1–R4 或「OI 安静」）
  · t = d 所属的月份（月份固定效应用），由 d 决定
  · y_idk：同一个合约、同一天、同一格的那些小时，收益先取平均
  · D_idk：这一格是该状态取 1，否则 0
  · α_j、λ_s：合约、月份固定效应
  · β：换成日频权重之后，标签相对「同向超阈行的其余行」的超额（dummy=0 组）
步骤二 · β
  回归拟合出 β。代码先把 y 和 0/1 标记双向去均值，再在残差上回归（见实验 1 的说明）。
步骤三 · SE 和 t
  û = ỹ − β · x̃ ；ψ = x̃ · û
  V = Σ_合约(Σψ)² + Σ_月份(Σψ)² − Σ_合约月(Σψ)²

`y` 不翻正：R1 是涨的状态，所以"越持久越涨"；R3 是跌的状态，镜像成"越持久越跌"。
梯度对日界不敏感：日界改到 06:00 / 12:00 UTC，R1 的"1 个"桶是 −19.6 / −19.2、"5+" 桶是
+34.4 / +33.8。R1 的梯度跨度 54bp，而基准（OI 安静行、同方向）的同样分桶跨度只有 **8.2bp**
（−6.1 / −3.2 / −2.7 / −0.1 / +2.1）。
**判定**：波动 16/16；收益 13/16 显著，但**方向与实验 1 相反**。
**结论**：四状态对**收益**的作用不是一个水平平移，而是**依赖信号持续性**——同一天里孤立出现的
信号反转、连续出现的信号延续。实验 1 的均值是"每小时等权"，被"同一天反复出现"的小时主导；
压成日频后，孤立信号的日子在数量上占多数，均值就翻负。
**能说 / 不能说**
- 能说：日频等权后，波动结论成立；收益结论不成立，且能定位到"当天出现几次"
- **不能说**实验 1 "错了"——它是每事件等权的口径，本身没错；也不能把这张表当成
  "日线事件定义"的检验（那是 1d 标签，另一件事）
- **报告必须同时报行级与日频两套数**，并说明它们是两个权重，不是同一个估计量的两个版本

## 附：为什么不做 IC（note §12 的条件句）

note §12 的原话是 **"IC by horizon, *if signal is converted into a ranked score*"** —— 条件句。
我们的信号是**阈值标签**（价格 × OI 的四格），不是连续分数，**条件不满足**。

**试过的版本（已删除，不交付）**：把标签压成 `price ∈ {±1}`、`four ∈ {+1,0,−1}` 算逐小时 Spearman。
不可用：① 分数只有 2–3 个取值 → 秩相关退化为 rank-biserial（"两组平均秩之差"），不是把币排出优劣；
② 每小时横截面只有约 13 个合约。所以它只是 Fig 5-7「纯价格价差」的秩版本，不构成独立证据。

**note 的核心问题已由三处回答**：实验 1b（交互 4/4 显著）、实验 5–9（价差全 0）、实验 3（波动 16/16）。

**真正的 IC 需要**连续分数（`price_change` / `oi_change` 的小时横截面 z 值）**加上更宽的横截面**
（全池约 47 个合约/小时，而不是事件行的 13 个）。`labels` 里已有这两列，但 `panel` 没携带——
重建后即可做 `regime_score = sign(price) × oi_z` 与 `price_z` 的对比。**列为 Phase 4 待办。**
