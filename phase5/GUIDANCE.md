## 0. 为什么有 v2

v1 的闸门判据是「Phase 4 的**对比**显著」，Phase 5 的策略赚的是「**水平**」。两者不是同一个估计量：

    level(neg) = level(neu) + contrast

对比为正只说明 `neg` 比 `neu` 好，不说明 `level` 为正。实测：

| 项 | contrast（v1 的闸门） | level（策略能赚的） |
|---|---:|---:|
| R3×neg h=1 | **+5.29bp**（p_bh 0.033） | **−0.67bp** |
| R4×neg h=1 | +2.47bp（p_bh 0.024） | +6.37bp |

v1 用左列开闸，右列才是可交易的东西。结果 M1a 在 OOS 净 Sharpe −3.92。

v2 改动四处，其余全部继承 v1：
1. **闸门改为 level 口径**，并写成可执行的三段：G0 取数 → G1–G4 判定 → G5 映射策略臂（§2）。
2. **策略对象由闸门产出**，不再是指定的 M1a/M1b/M2（§3/§4）。
3. **仓位改成 2% × 50 槽**（v1 的 10% × 10 槽在事件聚集时丢掉 15% 的事件却携带 72% 的毛边际，§7）。
4. **成本收敛为单一 taker 口径（20bp 往返），不做 maker/压力档**（§6）。

## 2. 闸门（Phase 4 → Phase 5）—— 按顺序执行

闸门只回答一个问题：**这个格子里有没有东西。**
成本与可执行性**不进闸门**，它们是 Phase 5 的判定项（§6/§9）。这是职责划分：闸门筛信号，Phase 5 测变现。

### G0 取数与口径

- 输入：`data/07_funding/base/p4_base_h={1,4,8,24}.parquet`（只读）。
- 事件：`cell ∈ {1,2,3,4}`，`state ∈ {0,1,2,3}`，其中 `state 2/3` 合并为 `high`。
- universe 已内含在 base 中（`in_universe & excl_reason=='ok'`），不额外筛。
- **水平变量 = `fwd`**（原始远期收益，bp）。`y_raw` 只用于 G2。
- 时间原点 `T0 = 2021-12-01T00:00Z`，`hour` 是自 T0 起的小时数，表示**时间点**（bar 收盘）。

### G1 水平显著（存在性）

对每个 `(cell c, funding s, h)`：

    统计量  t = mean(fwd) / se
    se      CGM 双向聚类：V = V_合约 + V_月份 − V_(合约×月份)
            V_g = sum_g( Σ_{i∈g} (y_i − ȳ) )² / n²
    检验    单边 H0: mean(fwd) ≤ 0
    多重性  BH，家族 = 同一 h 下的 12 个格，q < 0.05
    最小样本 n ≥ 400

### G2 非 beta

    mean(y_raw) ≥ 0

`y_raw = fwd − 同小时市场均值`。这一条挡掉「纯市场漂移冒充 funding 效应」。
反例：R3×neg h=24 的 level +8.88bp，但 `y_raw` −38.11bp。

### G3 非尾部

    median(fwd) > 0  且  1% 截尾均值 > 0

挡「几笔大赚撑起均值」。反例：R3×neg h=1 的 level −0.67bp、中位 +8.32bp。

### G4 稳定

分块：**自然年** Y22 2022-03..2022-12 / Y23 / Y24 / Y25 / Y26 2026-01..2026-08。

    ① 5 个自然年里 ≥4 个的 mean(fwd) > 0
    ② 最近 12 个月（2025-09..2026-08）的 mean(fwd) ≥ 0

两个条件同时满足才过。

为什么近期判据用滚动 12 个月、而不是「Y26 ≥ 0」：Y26 只有 8 个月，实测中 R4×mv-high h=8 的 Y26 = −1.86、h=4 的 −0.08，
判据在 0 附近一刀切会因 0.1bp 翻转结论。滚动 12 个月与「Y26 ≥ 0」在本数据上给出同样的臂集合，但没有刀口问题。

### G5 映射到策略臂

- 每个过 G1–G4 的格 → **一条规则**：方向 long，持有期 = h，入场/出场照 §5。
- 同一 `(cell, funding)` 的不同 h **各自成臂，不合并**。
- 来自 Phase 3 维度（`regime × mkt_vol`）的格同样合法，标 `src=P3`。

## 4. 策略臂

**臂（arm）= 一个能被独立回测的完整策略版本。** 术语借自临床试验的 trial arm（试验组 / 对照组）：
同一套测试协议下并列跑的几个候选，各自出一条 PnL 曲线、各自一套指标，最后横向比较。
本项目里一条臂由三件事定死：**选哪些事件 × 持有多久 × 仓位怎么算**。

与之相对的**变体（variant）只改仓位算法**，不改事件定义与持有多久：
同一臂的 `base` 与 `V1` 是同一个策略的两种风险版本，不算两条臂。

一个具体的臂 = 一条规则 + 一个持有期。所以「R4×负funding」不是臂，「R4×负funding 持有 8h」才是。

| 臂 | 规则 | 角色 | 判定用途 |
|---|---|---|---|
| **A1** | `cell=4 & state=0` → long，**8h** | 主臂（note 假设） | 失败线适用 |
| B1 | `cell=4 & mkt_vol=high` → long，**1h** | 参照（无 funding 条件） | 不判定，只报增量 |

每条臂跑两个变体：
- **base**：等名义，2% / 笔。
- **V1 波动率缩放（因果、反向）**：σ = 入场前 24 根已收盘 bar 的对数收益标准差；
  `target` = 训练期该臂事件 σ 的中位数；`size = clip(σ / target, 0.5, 1.5)`。
  **波动高 → 加仓**。与教科书 vol-target 相反：本样本毛边际随波动上升，逆着缩放会砍掉最好的交易。

## 5. 回测协议（继承 v1 §4，一处修正）

### 入场
- 事件后**下一根 bar 的开盘**，市价。
- 缺 bar：缺口 ≤ 2 根用下一根可用 bar 的开盘，持有期从该 bar 起算；> 2 根跳过，计数。
- 不用 stale price、不 impute。

### 出场
- 持有到**入场时刻 + h** 的收盘（h=1 时即入场 bar 本身的收盘）。
- 合约下架：最后一个可交易 bar 的收盘平仓。
- 主回测无止损。

### 重叠
- 同一合约已有未平仓时**不新开、不加仓**，只保留第一笔。

### 成本
- 见 §6。

### Funding
- 按**真实结算时间戳**整笔收付（不用 00/08/16 固定网格：实测 4h 结算占 45%，2026 年升到 72%）。
- 窗口 `(入场时刻, 出场时刻]`。
- 负 funding 时 long **收**。
- 缺结算点按 0 carry 处理并计数。

### 异常值
- 不 winsorise、不剔除（Phase 3 冻结口径）。
- 另报「剔除 LUNA 后」一行作敏感性。

## 6. 成本口径（单一：taker）

### 唯一口径

| 项 | 单边 | 往返 |
|---|---:|---:|
| taker 费率（Binance USDⓈ-M VIP0） | 5bp | |
| 滑点（$10k clip，主流 alt 永续） | 5bp | |
| **合计** | **10bp** | **20bp** |

全部计算只用这一档。**不做 maker、不做压力档。**

### 为什么不做 maker

限价单的成交概率与「价格即将逆向」负相关（adverse selection）：不成交时价格朝有利方向走，成交时往往已经要亏。
要把它变成可用估计，需要 post-only + 队列位置模型 + 校准 fill rate，以及盘口与逐笔成交数据。
本项目只有 1h K 线，**做不了**。硬套 maker 费率会得到一个系统性偏乐观的数，比不报更糟。

### 保留的换算列（不是第二档成本）

    cost* = 毛边际/笔 = (price_pnl + funding_pnl) / notional

它只是把毛边际换成 bp，回答「要多少成本才能活」，不额外跑任何东西。

本数据上的实测（可执行账本）：

| 臂 | 毛边际/笔 | cost* | 对 20bp |
|---|---:|---:|---:|
| A1 R4×neg @8h | 10.94bp | 11bp | −9.06 |
| B1 R4×mv-high @1h | 9.86bp | 10bp | −10.14 |

## 7. 组合与仓位

- 初始资金 **$100,000**。
- **每个信号 2% 名义**（= 1/50 个风险单位），等名义。
- 总敞口 ≤ **50 × 2% = 100%**（1×）。超了跳过并计数。
- 满仓时同一时刻的候选按**固定 seed 随机排序**决定先后（不按合约代码，避免上市先后偏差）。
- 不做再平衡；仓位持有到期。
- 单合约 ≤ 20%：V1 下最大 1.5 × 2% = 3%，**永不触发**，只作记录。

## 8. 切分与 in-sample 声明

### 切分（沿用 v1）
- 主切分：训练 2022-03..2024-05（27 月），测试 2024-06..2026-08（27 月）。
- 3 折 walk-forward：18 训练 / 9 测试，步长 9。
- final holdout：2026-06..2026-08。

### 必须声明的（v2 新增）
> **本文件在看过全样本结果之后写定。** 因此本报告的所有数字都是 **in-sample**，不构成盲测 OOS。
> 保留切分是为了报告分段稳定性、与 v1 可对比，不是为了声称样本外验证。

任何「样本外」措辞都是错误的。报告首页必须写这句。

## 9. 指标与 baseline

### 指标（每臂 × 每变体 × 每窗口）
- 净 Sharpe（**唯一显著性指标**）+ 5 日 block bootstrap 95% CI
- 毛 Sharpe（成本前，用于归因）
- 年化收益、年化波动（365 天年化）、最大回撤
- **毛边际 cost***（= 毛边际/笔，仅换算，不是第二档成本）
- price / funding / cost 三段拆分（每笔 bp）
- by-regime、by-asset
- n 笔数、跳过数（按原因：缺口 / 重叠 / 满仓）、缺失结算点数

### baseline（6 条，同方向、同持有期、同 universe）
1. **price-alone**：同方向的价格事件，不看 OI/funding
2. **random timing**：同月度笔数，随机合约 + 随机小时（固定 seed）
3. **buy-and-hold**：`03_reference/universe_membership.parquet` 的月度 50 合约等权，月初重置，按换手计成本
4. **OI-alone**：OI 越阈，不看价格方向/funding
5. **funding-alone**：`state=0`，不看价格/OI
6. **price+OI（不含 funding）**

### 必报的对照读数
- **本臂 vs price+OI** → funding 的增量
- **本臂 vs price-alone** → OI 的增量
- **`y_raw` 占 level 的比例** → 多少是 beta

## 14. 给接手 agent 的最后一句话

这份 Phase 5 的任务不是证明发现有效，而是**把一个统计上真实的水平效应，按真实成本和真实组合约束，判一次生死**。
预期结局是「未通过」——那是有信息量的结论，不是失败。
任何为了让结果好看而调阈值、换窗口、改成本、剔除事件的操作，都会让这份工作失去唯一的价值。
